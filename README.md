# Redraft

AI-powered cover letter and outreach message polisher.

## About

Redraft is a simple web application that uses Google's Gemini API to improve rough cover letters and outreach messages.

It makes writing more professional, clear, and confident while keeping the original meaning and key details intact.

## Features

- Polishes rough cover letters and outreach messages
- Improves grammar, clarity, and professional tone
- Preserves the original meaning and key details
- Shows a short list of changes made
- Simple and responsive web interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Vercel
- Google Gemini API
